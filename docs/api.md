# API reference

Base URL `http://localhost:8000`. Interactive docs at `/docs` (OpenAPI generated by FastAPI).

| Method | Path | Body / params | Response |
|---|---|---|---|
| GET | `/healthz` | — | `{"ok": true, "deepgram": bool, "hf": bool, "anthropic": bool, "eleven": bool}` |
| POST | `/v1/meetings` | multipart: `file` (wav/mp3/m4a/flac/ogg/webm/mp4, ≤1 GiB), `multichannel` bool, `num_speakers` int, `keyterms` "a,b,c" | `202 {"id", "status": "queued"}` |
| GET | `/v1/meetings/{id}` | — | `{"id", "status": queued\|running\|done\|failed, "timings", "error"}` |
| GET | `/v1/meetings/{id}/transcript` | — | `Transcript` JSON; `409` if not ready |
| GET | `/v1/meetings/{id}/record` | `format=json\|md` | `MeetingRecord` JSON or Markdown |
| POST | `/v1/meetings/{id}/recap-audio` | — | `audio/mpeg` (ElevenLabs), cached |
| POST | `/v1/livekit/token` | `{"room", "identity", "name"?}` | `{"url", "token"}`; token dispatches the `meeting-notes` agent |

## Example

```bash
ID=$(curl -s -F file=@ES2011a.Mix-Headset.wav -F keyterms="remote control,kinetic" \
      localhost:8000/v1/meetings | jq -r .id)
while [ "$(curl -s localhost:8000/v1/meetings/$ID | jq -r .status)" != "done" ]; do sleep 10; done
curl -s "localhost:8000/v1/meetings/$ID/record?format=md"
curl -s -X POST localhost:8000/v1/meetings/$ID/recap-audio -o recap.mp3
```
